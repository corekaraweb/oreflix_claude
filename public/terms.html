利用規約

本規約は、OREFLIX(以下「本サービス」)の利用条件を定めるものです。本サービスを利用することで、本規約に同意したものとみなされます。

1. サービス内容

本サービスは、サイト運営者があらかじめ選んだYouTubeの再生リストを、閲覧しやすい形式で表示する個人運営のWebサイトです。 動画データの取得および再生には、YouTube API サービスを利用しています。

2. YouTube利用規約への同意

本サービスを利用する方は、本規約に加えて、YouTube利用規約 に拘束されることに同意するものとします。動画の再生は、YouTubeが提供する標準の埋め込みプレーヤーを通じて行われ、本サービスが動画データを改変・保存・二次配布することはありません。

3. 禁止事項

  • 本サービスまたはYouTube API サービスの不正利用、妨害行為
  • 本サービスを経由した動画・音声データのダウンロード、複製、再配布
  • 本サービスのソースコードの逆コンパイル、リバースエンジニアリング
  • 法令または公序良俗に反する行為

4. 免責事項

本サービスは、表示されるコンテンツの正確性・完全性・有用性についていかなる保証も行いません。 YouTube側の都合により、動画の削除・非公開化・再生リストの変更が予告なく発生する場合があります。 本サービスの利用により生じた損害について、運営者は責任を負いません。

5. 規約の変更

本規約は、予告なく変更されることがあります。変更後の規約は、本ページに掲載した時点で効力を生じるものとします。
