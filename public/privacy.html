プライバシーポリシー

本サイト(OREFLIX、以下「本サービス」)は、YouTubeの再生リストをNetflix風の画面で閲覧できる個人運営のWebサイトです。 本サービスはYouTube API サービスを利用しています。

YouTube API サービスの利用について

本サービスの動画情報の取得・再生には、YouTube API サービスを使用しています。 本サービスを利用することにより、以下の規約・ポリシーに同意したものとみなされます。

  • YouTube利用規約
  • Googleプライバシーポリシー
  • 当サイトの利用規約

動画は初回アクセス時にご案内する同意画面で「同意する」を選択いただくまで再生されません。同意いただくまでは、YouTubeが提供するサムネイル画像のみを表示します。

本サービスが取得する情報

本サービス自体は、会員登録機能を持たず、氏名・メールアドレスなどの個人情報を収集しません。 ただし、動画再生時にはYouTubeの埋め込みプレーヤーを使用しており、その際にGoogle/YouTubeが独自にCookie等を通じて情報を取得する場合があります。これらの取り扱いは前述のGoogleプライバシーポリシーに従います。

端末への情報保存(ローカルストレージ)について

本サービスは、上記の同意画面で「同意する」を押したことを記憶するために、お使いのブラウザのローカルストレージ(localStorage)に同意済みであることを示す情報を1件保存します。 この情報は外部に送信されることはなく、ブラウザのサイトデータを削除すると消去されます。

アクセス解析等について

本サービスでは、サーバーの標準的なアクセスログ(アクセス日時・IPアドレス等)を、不正利用防止(ログイン試行制限など)の目的で一時的に保持することがあります。第三者に提供することはありません。
