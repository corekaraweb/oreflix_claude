# OREFLIX

YouTubeの再生リストを取り込んで、Netflix風のUIで閲覧・再生できるWebアプリです。
フロントエンドはReact + Vite、バックエンドは軽量なPHPで構成されています。

## 構成

- **フロントエンド**(このリポジトリ直下の `src/`): Netflix風の画面表示・検索・再生を担当するSPA。
- **バックエンド**(`server/`): YouTube Data APIキーと再生リストの一覧をサーバー上で一元管理するPHP製の小さなAPI/管理画面。全訪問者に同じ再生リストを表示するため、また、APIキーをブラウザに一切渡さないために使います。

PHPをまったく使わずお試しで動かしたいだけの場合を除き、本番公開には `server/` のデプロイが必須です。デプロイ手順は **[server/README.md](server/README.md)** を参照してください。

## 主な機能

- 再生リスト単位でのNetflix風の横スクロール行(ロウ)表示
- カードにマウスを乗せると自動でプレビュー再生(ミュート・ループ)
- クリックでモーダルを開き、通常のYouTubeプレーヤーで再生
- 読み込んだ全再生リストを横断したタイトル検索
- APIキー・再生リストはサーバー側で一元管理し、全訪問者に同じ内容を表示
- パスワード保護された管理画面(`/admin/`)から、サイト管理者だけが設定を変更可能

## ローカル開発

PHP(8.1以上を推奨)がインストールされている必要があります。ターミナルを2つ使い、それぞれ起動してください。

```bash
npm install
npm run dev:php   # PHPバックエンドを http://localhost:8080 で起動
npm run dev       # Viteフロントエンドを起動
```

ブラウザで表示されたURL(通常は http://localhost:5173 )を開いてください。`/api/*` と `/admin/*` へのリクエストは、Viteの開発サーバーが自動的にPHP側(`http://localhost:8080`)へ転送します(`vite.config.js` 参照)。

初回アクセス時は `/admin/` で管理者パスワードを設定し、YouTube Data APIキーと再生リストを登録してください(詳細は [server/README.md](server/README.md))。

## YouTube Data API キーの取得

1. Google Cloud Console でプロジェクトを作成します。
2. 「APIとサービス」→「ライブラリ」から **YouTube Data API v3** を有効化します。
3. 「認証情報」→「認証情報を作成」→「APIキー」でキーを発行します。
4. 発行したキーは「APIキーの制限」で使用予定のサーバーのIPやリファラーに制限することを推奨します(第三者による不正利用を防ぐため)。

取得したAPIキーは、ブラウザではなく `/admin/` の管理画面(サーバー側)に登録します。

## 再生リストの追加

YouTubeの再生リストページのURL(例: `https://www.youtube.com/playlist?list=XXXXXXXX`)、または `list=` の値(再生リストID)そのものを、`/admin/` 管理画面の入力欄に追加してください。追加した再生リストごとに1つの横スクロール行が作られます。

チャンネルの「アップロード動画一覧」を丸ごと表示したい場合は、そのチャンネルの「アップロード」再生リストID(`UU` + チャンネルIDの`UC`以降の文字列)を追加することでも表示できます。

## 注意事項

- YouTube Data API には1日あたりの無料利用枠(クォータ)があります。サーバー側でレスポンスをキャッシュしていますが、多数の再生リストや大きな再生リストを追加すると消費が早くなるため、必要な範囲で追加してください。
- 各再生リストは最大200本(4ページ分)まで自動読み込みします。

## 本番ビルド

```bash
npm run build
```

`dist/` に出力される静的ファイルと、`server/` 以下のPHPファイルをレンタルサーバーにアップロードします。手順は [server/README.md](server/README.md) を参照してください。
